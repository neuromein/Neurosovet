## Что такое Нейросовет?

Нейросовет — это структурированная методология мультимодельных AI-дебатов с итеративным арбитражем. Вместо простого сравнения ответов разных нейросетей, метод реализует строгий протокол:

- **Итеративные раунды** (2–4), в которых модели критикуют и уточняют позиции друг друга
- **Антиподхалимский протокол** (8 правил), не позволяющий моделям слепо соглашаться с арбитром
- **Дельта-анализ** — классификация реакции каждой модели на критику по 4 типам: Интеграция, Подхалимство, Устойчивая позиция, Аргументированное несогласие
- **Самокоррекция арбитра** — арбитр обязан пересмотреть позицию при сильных контраргументах моделей
- **Культурно-методологический фильтр** — учёт различий между западными, китайскими и российскими моделями
- **Сигналы конвергенции** — чёткие критерии остановки или продолжения раундов
- **Обязательный веб-поиск** арбитра для фактических и time-sensitive вопросов
- **Верификация фактических противоречий** — явный протокол разрешения конфликтующих утверждений

## Как это работает

1. Вы задаёте один вопрос 3–5 нейросетям, каждая получает **промпт участника**
2. Вы читаете все ответы целиком (вы — оркестратор, а не почтальон)
3. **Модель-арбитр** анализирует ответы по жёсткому протоколу: классификация задачи → индивидуальная оценка → матрица сравнения → слепые зоны → культурный анализ → синтез
4. Вердикт возвращается моделям — они обязаны обосновать каждое изменение позиции конкретной цитатой
5. Арбитр проводит **дельта-анализ**: кто реально улучшился, кто просто согласился, кто устоял, кто аргументированно возразил
6. Цикл повторяется 2–4 раза. На практике 2–3 раунда дают 80–90% результата

## Быстрый старт

Полное руководство — в файле `guide/neurosovet-guide.pdf`. Краткая версия:

### 1. Настройте арбитра

Выберите самую сильную модель (актуальный рейтинг — [LMSYS Leaderboard](https://arena.ai)). У арбитра обязательно должен быть включён веб-поиск.

- **Claude** (рекомендуется на май 2026): создайте Project, вставьте промпт арбитра в Custom Instructions
- **Gemini**: создайте Gem с промптом арбитра
- **ChatGPT**: создайте Custom GPT или вставляйте в начало каждого чата

### 2. Настройте участников

Откройте новый чат в каждой нейросети (рекомендуется 3–5). Вставьте промпт участника + ваш вопрос.

**Рекомендуемые модели:** ChatGPT, Claude, Gemini, Grok, DeepSeek, Qwen. Для вопросов по российскому рынку — GigaChat или YandexGPT.

### 3. Запустите совет

Подробный процесс — в руководстве, раздел «Рабочий процесс».

## Для каких задач

- Стратегические решения — выход на рынок, build vs buy, реакция на конкурента
- Прогнозы и оценка рисков — эволюция рынка, регуляторное воздействие, технологические тренды
- Сложный анализ с неполной информацией
- Подготовка к публичным выступлениям — стресс-тест аргументов, антиципация контраргументов
- Инвестиционные и кадровые решения
- Исследовательские вопросы — разрешение противоречивых исследований

## Не используйте для

- Простых фактических вопросов
- Задач с единственным правильным ответом
- Срочных вопросов
- Рутинных задач (письмо, перевод, редактирование)
- Чисто субъективных задач
